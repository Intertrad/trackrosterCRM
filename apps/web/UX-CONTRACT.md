## Navigation and scope

`/workspace` is a role-filtered tool catalogue. `/workspace/[module]` hosts the reviewed operational modules. Existing task-oriented pages remain canonical for daily work, map, route execution, assignments, approval, imports, exports, messages and account management. Design ZIP screens representing a drawer, confirmation or failure state remain states within these flows rather than redundant routes. Platform authority is explicitly returned by the server from active identity-level grants and is never inferred from tenant administration.

Committed filters and cursor are stored in the URL. Writes and drafts are not put in URLs or persistent browser storage. Clearing filters resets pagination. Pagination reports records on the current page, never an invented total. Missing/denied reads remain distinct from empty data. Server errors carry request references when provided.

## Editing and concurrency

An editing session snapshots its values and ETag. Background reads update list data without replacing that draft. A stable idempotency key is retained for a retry of the same action, values and version. A 412 preserves the draft; an explicit reload merges the latest unchanged fields and keeps local changes, then requires another save after review. No retry silently removes If-Match. Inputs serialize only supported fields and retain false, zero and explicit nullable clears. External service settings use their documented open-ended object contract; malformed objects are rejected locally.

Dirty editing uses an app-owned discard dialog for close/link navigation and the browser unload protection for reload/close. Browser history traversal is not used as an editor route; the local overlay remains in the parent route. Back navigation while a dirty overlay is open must be verified before claiming full draft recovery across every browser.

## Live updates and offline behavior

The app uses near-real-time polling, not a WebSocket/SSE subscription. Changes from other users appear at the next poll; local and cross-tab mutations invalidate immediately. No mutation is automatically queued or replayed while offline. Show an offline banner, preserve input, and let the user retry after reconnecting. Reservation availability remains advisory until the server accepts the claim/start; visual freshness never grants authority.

## Admin base workflow

Filters, sort, cursor and list/map mode are restorable in the URL. The selection is transient and clears on a filter change. No control selects unseen search results. The map explicitly covers only loaded rows. Assignment selectors reuse RecordPicker with active campaign, owning-organization team and exact team prospector filters. Previewing never mutates. Enrollment and assignment are separate confirmed writes; closing after enrollment preserves the real enrollment and explains that consequence. Conflicts require review before another apply.

Daily assignment polling preserves visible rows while loading. Lost authorization clears those rows. Shared overlay focus remains stable across draft edits and live renders; close uses the latest callback and restores the opener. Browser evidence and regression commands for this extension are in `../../output/reference-integration-qa/REPORT.md`.
