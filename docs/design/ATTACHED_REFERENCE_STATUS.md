The canonical tokens and responsive component rules are in `apps/web/DESIGN.md` and `apps/web/UX-CONTRACT.md`. Navy navigation, blue primary actions, lime accents, readable tables and a mobile daily workflow are the visual direction. Existing manager/director capabilities remain available. The reference does not itself authorize removing those roles.

The workbook import supplies the administrative prospect base. It does not fabricate contact history, campaign membership, assignments, reservations, sessions, consent or dashboard outcomes. Prospectors see the records made available through their real campaign/assignment scope.

The visual pass also updates the shared canvas, cards, tabs, brand mark, responsive navigation and primary French labels. Connected screens were inspected at desktop and phone widths; selected side-panel and failure/retry workflows were exercised. This is not pixel parity for unsupported session, template, enrichment and company-eligibility features.
