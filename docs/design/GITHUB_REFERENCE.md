# GitHub frontend reference

The user's current visual authority is [libehon/TrackRoster/TrackRoster](https://github.com/libehon/TrackRoster/tree/main/TrackRoster), inspected at revision `a8a5455` on 29 September 2026. The standalone Vite application was run locally and its rendered pages inspected alongside source CSS. Captures are in `output/github-design-reference/`.

Original assets `src/image/logo.png` and `logo-greyed.png` are retained as `apps/web/public/brand/roster.png` and `roster-muted.png`. Palette, typography, sidebar geometry, card/input/button dimensions, compact tables and segmented tabs come from `src/index.css`, `src/shared/ui/ui.css`, `src/sidebar/Sidebar.css` and the page styles. These are implemented through the connected app's shared controls and tokens.

The reference's browser-local store and demo account logic were not installed into the connected application. The backend remains authoritative for authentication, tenant scope, permissions, assignments, contact availability, reservations and writes. Live updates use 10-second polling (5 seconds for messages/jobs), immediate mutation invalidation and focus/reconnect refresh.

This is a connected design adoption with the differences above, not a claim of pixel-identical or complete feature parity. Verification and local deployment details are in `output/github-design-implementation/REPORT.md`.
