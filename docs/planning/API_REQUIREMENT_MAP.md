## Non-HTTP requirements

- TR-130 owns notification/reservation/import/export realtime channels, outbox delivery, reconnect and scope enforcement.
- TR-141 owns message realtime events on that authorized delivery substrate.
- TR-108 owns versioning, compatibility, DTOs, cursor pagination, idempotency and optimistic concurrency conventions.
- TR-103/TR-104 own restricted roles, transaction-local scope, RLS and DB append-only enforcement.
- TR-152/TR-153 own readiness, resilience, telemetry and verified recovery/release gates.
- TR-147 must add explicit tenant support-approval/rejection contracts absent from the supplied list.
- TR-138 must add privacy-request, legal-hold and retention-operation contracts absent from the supplied list.

Exact source section and row associations are retained in [backlog.json](backlog.json).
